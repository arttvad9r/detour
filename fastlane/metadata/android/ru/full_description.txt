Detour — open-source сетевой клиент для Android, в котором можно выбрать, как каждое приложение выходит в интернет.

<ul>
<li><b>Прямой</b> — обычное подключение к сети.</li>
<li><b>VPN</b> — VLESS Reality, HTTPS-подписки, WARP или AmneziaWG для выбранных приложений.</li>
<li><b>DPI</b> — нативный ByeDPI только для тех приложений, которым он нужен.</li>
</ul>

Detour также умеет выбирать серверы подписки, сортировать их и проверять задержку, настраивать DNS внутри туннеля, использовать рекомендуемые и собственные стратегии ByeDPI, тестировать стратегии, подключаться из плитки быстрых настроек, подключаться при запуске, экспортировать и импортировать конфигурацию и менять темы оформления.

Аккаунт Detour не нужен. Чувствительные данные VPN-профилей хранятся локально с шифрованием на основе Android Keystore.

Detour находится на стадии pre-release. Проверяйте импортированные конфигурации перед подключением.
