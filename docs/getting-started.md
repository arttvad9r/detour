# Как пользоваться Detour

## Установка

1. Откройте [последний релиз](https://github.com/arttvad9r/detour/releases/latest) и скачайте файл `detour-…-arm64.apk`.
2. Откройте его на телефоне. Android попросит разрешить установку из браузера или файлового менеджера, разрешите.

Нужен Android 10 или новее и 64-битный телефон.

**Play Protect** может предупредить, что приложение неизвестно: Detour не публикуется в Google Play. Не отключайте Play Protect. Если он предлагает проверить приложение, согласитесь. Устанавливайте только APK с этой страницы релизов.

<details>
<summary>Как проверить, что APK не подменён</summary>

Рядом с APK в релизе лежит файл `.sha256`. Скачайте оба в одну папку на компьютере и выполните:

```bash
sha256sum -c detour-<версия>-arm64.apk.sha256
```

Должно появиться `OK`. Если нет, не устанавливайте этот файл.

</details>

## Добавить VPN

Этот шаг нужен, только если какие-то приложения должны идти через VPN. Для одного DPI его можно пропустить.

**Настройки → VPN-профили → Добавить профиль**, затем выберите, что у вас есть:

| Что у вас есть | Что выбрать |
| --- | --- |
| Ключ, начинающийся с `vless://` | **Добавить VLESS** |
| Ссылка на подписку `https://…` | **Добавить подписку** |
| Ключ Amnezia `vpn://…` | **Вставить ключ Amnezia** |
| Файл WARP или AmneziaWG (`.yaml` или `.conf`) | **Импортировать файл конфигурации** |

Обычный WireGuard-файл без параметров AmneziaWG Detour не примет. Подробнее: [WARP и AmneziaWG](warp-profiles.md).

У подписки можно выбрать конкретный сервер, найти его поиском и проверить пинг.

> Ключи, подписки и файлы конфигурации — это ваши пароли от VPN. Не выкладывайте их в открытый доступ.

## Начальная настройка

На чистой установке Detour предложит выбрать цель: только YouTube/DPI, ключ VLESS,
подписка или WARP/Amnezia. Мастер откроет нужную форму профиля и выбор приложений.
После импорта выберите профиль в списке, назначьте приложениям VPN или DPI и вернитесь
в мастер кнопкой **«Продолжить»**. Когда всё готово, нажмите **«Подключить»** и подтвердите
разрешение Android. После подключения кнопка **«На главный экран»** завершит настройку.

Мастер можно пропустить и открыть позднее: **Настройки → Помощь → Пройти настройку заново**.
При обновлении уже настроенного приложения он автоматически не открывается.

## Выбрать маршруты

**Маршруты приложений** (на главном экране или в настройках). Для каждого приложения выберите:

- **Прямой** — обычный интернет, без VPN.
- **VPN** — через выбранный VPN-профиль.
- **DPI** — обход блокировок и замедлений без сервера.

Разумно начать так: всё напрямую, а VPN и DPI включить только тем приложениям, которым это действительно нужно. Системные приложения по умолчанию скрыты, их можно показать переключателем вверху.

Поиск и фильтры **Все / Прямой / VPN / DPI** помогают найти нужные приложения.
Чтобы назначить маршрут сразу нескольким, нажмите **«Выбрать»**, отметьте приложения
или нажмите **«Выбрать все в списке»**, затем выберите маршрут внизу экрана.
Выбираются только приложения текущего списка с учётом поиска и фильтров.
При смене поиска, фильтра или видимости системных приложений выбор сбрасывается.

Нажмите на название приложения, чтобы увидеть назначенный маршрут, состояние Detour
и причины, которые мешают подключению. Это проверка настроек, а не мониторинг трафика.

## Подключиться

Нажмите **«Подключить»** на главном экране. В первый раз Android спросит разрешение на VPN, разрешите.

Отключить можно кнопкой на главном экране, из уведомления или плиткой в шторке. Плитку Detour можно добавить через редактирование шторки быстрых настроек.

Если что-то поменять при включённом туннеле, Detour сам перезапустит его с новыми настройками.

## Если DPI не помогает

Обход DPI работает по-разному у разных провайдеров. Подходящую стратегию можно подобрать:

1. Отключите другие VPN, иначе тест покажет неверный результат.
2. Откройте **Настройки → Обход DPI → Тест стратегий**.
3. Выберите сайты, которые хотите открыть (например, YouTube), и запустите тест.
4. Посмотрите результат по сервисам и нажмите **«Применить лучшую из проверенных»**.

По умолчанию тест делает три попытки на каждый адрес. В рейтинге сначала учитываются
адреса, ответившие без сбоев, затем число успешных проверок и время ответа. При нуле
успешных проверок стратегия не предлагается к применению. Частичный результат отмечается явно.
Тест проверяет доступность по HTTPS и не гарантирует воспроизведение видео или работу всего приложения.

После завершения, отмены или ошибки можно сохранить JSON кнопкой **«Сохранить диагностический отчёт»**.
В нём есть версии Detour/Android, выбранные группы сервисов, параметры теста и сводные результаты.
VPN-ключи, подписки, список приложений, IP-адреса, домены, пользовательские команды и логи не экспортируются.

## Другие настройки

- **DNS**: Cloudflare, Google, AdGuard, свой IP или DoH-адрес. Менять не обязательно.
- **Подключаться при запуске**: туннель включается, когда открываете Detour.
- **Экспорт / импорт**: перенос всех профилей и маршрутов на другой телефон. В файле есть ваши ключи, храните его как пароль.
- **Оформление**: светлая, тёмная и цветовые темы.

## Проблемы

**«Не выдано разрешение на VPN».** Нажмите «Подключить» ещё раз и разрешите. Если включён другой VPN, сначала выключите его: Android разрешает только один VPN.

**«Сначала выберите или импортируйте VPN-профиль».** Какому-то приложению выбран маршрут VPN, а профиля нет. Добавьте его или переключите приложение на «Прямой» или «DPI».

**«Приложения с общим UID нельзя безопасно маршрутизировать».** Некоторые системные приложения Android работают под одним общим идентификатором. Detour не может направить одно из них, не задев остальные, поэтому отказывается. Верните таким приложениям маршрут «Прямой».

**Серверы подписки не появляются.** Проверьте, что ссылка полная и начинается с `https://`, и обновите подписку.

Не нашли ответ? Создайте [issue](https://github.com/arttvad9r/detour/issues). Только не прикладывайте ключи, подписки и файлы экспорта.
