# Repository media assets

`screenshots/` holds the README gallery: `en-*.jpg` for `README.md`, `ru-*.jpg` for `README.ru.md`.

They are captured from a release build on an emulator in Android demo mode, with synthetic profiles (`nl.example.com`, generated keys) and placeholder apps, then resized to 540 px wide.

## Rules

- Capture the real app, not mockups, and keep the shots aligned with the current UI.
- Use synthetic data only: never real keys, subscription URLs, `vpn://` payloads, backups or personal notifications.
- Record the source and license here for any third-party visual asset.
